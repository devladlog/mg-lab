# Demo shot list — Power BI #2 Advanced DAX

Like episode 1, this is **local only**: no tenant, workspace or licence. Power BI Desktop (free) on Windows runs the
DAX; everything else was built and tested in the Linux container.

## What was verified where

| Step | Verified in the container | Needs Windows + Power BI Desktop |
|---|---|---|
| TMDL with 14 measures (multi-line, descriptions) | loaded by TOM; `dax-lint`: 0 findings; 23 xUnit tests | refresh + **running the DAX** |
| 5 saved queries (`DAXQueries/*.dax`) | references checked by `dax-lint`; columns match expected CSVs | **running them** in DAX query view |
| Expected results | Python reference, 40 pytest tests | **compare on screen** (table below) |

The one assumption worth watching: queries 01 and 04 filter `'Date'[Year]` / group by `'Date'[Year Month]` and
expect time-intelligence filters on `'Date'[Date]` to replace them (marked date table). If query 01 shows different
**Sales PY / YTD / Last 3 Months** values, note it and tell the maintainer before publishing.

## Prerequisites
- Windows PC with current Power BI Desktop. Cost: free.
- Episode 1 done or at least its setup: CSVs in `C:\MGLab\power-bi\star\` (same files: `src/data/star`).
- Auto date/time off (File > Options and settings > Options > Global > Data load).

## Setup
1. Open `src/ContosoSales.pbip` (this episode's copy) and **Refresh**. Fallback if the project doesn't open: blank
   report → **TMDL view** → paste `src/ContosoSales.SemanticModel/TMDLScripts/create-model.tmdl` → **Apply** →
   **Refresh** (generated by `dax-lint --script`, as in episode 1).
2. Open **DAX query view**. The five files in `src/ContosoSales.SemanticModel/DAXQueries` should appear as query tabs
   (Desktop saves tabs there; loading hand-added files hasn't been observed yet). If they don't, create five tabs with
   the same names and paste each file.
3. Make the result grid big (drag the splitter up) and zoom the editor to 130 %.
