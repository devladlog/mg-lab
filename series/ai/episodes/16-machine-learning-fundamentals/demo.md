# Demo shot list — DEVLADLOG AI #16 (Machine learning fundamentals)

Everything is real and local: **scikit-learn trains real models on the synthetic ticket table** on the recording laptop. There is no
Azure resource, no tenant object, no licence and no cost in this episode: the topic is how to judge a model, not an Azure service
(Azure Machine Learning appears only in the references and in the next episodes). The five `screen` scenes are terminal captures of
`python -m mlbasics ...`. The 43 pytest tests also run on real scikit-learn (no test doubles). If `train` ends with "do not ship",
keep that on screen: it is the episode.

## Lab environment

| Item | Value |
|---|---|
| Recording machine | Lab Windows laptop: Windows Terminal (PowerShell or WSL), Python 3.10+ (tested with 3.13) |
| Software | `pip install -r requirements.txt` in a fresh venv: numpy, pandas, scikit-learn, joblib, pytest |
| Azure / M365 | None |
| Data | Synthetic and fictional, generated by `mlbasics.data` (fixed seed). Employee ids are `E0000`-style, no real people or tickets |
| Cost | €0. Runtime: `compare` about 10 s, `train` about 15 s on 2 shared CPUs (faster on the laptop) |

## Setup (off camera)

```bash
cd series/ai/episodes/16-machine-learning-fundamentals
python -m venv .venv && . .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m pytest tests -q                           # expect 43 passed
export PYTHONPATH=src                               # PowerShell: $env:PYTHONPATH = "src"
cat > ticket.json <<'EOF'
{"priority": "P1", "category": "network", "department": "finance", "language": "pt", "hour_opened": 22,
 "weekday": 6, "queue_backlog": 18, "attachments": 0, "text_length": 240, "is_vip": 0}
EOF
```

Terminal: dark theme, font ≥ 16 pt, 1920×1080, short prompt (no user/host name). `train` is run on camera, so run `python -m mlbasics train --out build`
once off camera first only to warm the disk cache; the on-camera run must be a fresh one.

## Screens to capture

| Scene id | File | What must be on screen |
|---|---|---|
| `audit-screen` | `screens/audit.jpg` | `python -m mlbasics audit ; echo exit=$?`: counts, prevalence, always-predict-no accuracy, the single-column AUC table with `first_response_minutes` marked SUSPECT, `exit=1`. Then `python -m mlbasics audit --drop first_response_minutes ; echo exit=$?`: no SUSPECT line, `exit=0`. |
| `baseline-screen` | `screens/baseline.jpg` | `python -m mlbasics baseline`: the no-skill row and the logistic row, accuracy next to AUC and AP, and the prevalence line. |
| `compare-screen` | `screens/compare.jpg` | `python -m mlbasics compare`: five rows, the "shared people" column (0 for the group rows) and both models' AP and AUC. Cut the compute wait. |
| `depth-screen` | `screens/depth.jpg` | `python -m mlbasics depth`: train AP rising to 1.000 while validation AP peaks and falls; the best-validation line. |
| `train-screen` | `screens/train.jpg` | `python -m mlbasics train --out build ; echo exit=$?`: CV ranking, chosen model, threshold, the single test evaluation, the cost comparison, RESULT, saved paths, exit code. Then `python -m mlbasics score ticket.json` (risk, threshold, FLAG / normal queue), and `cat build/model_card.json` scrolled to `excluded`, `threshold` and `not_for`. |

Optional b-roll: `python -m mlbasics data --out build/tickets.csv` and open the CSV in VS Code to show the columns.
