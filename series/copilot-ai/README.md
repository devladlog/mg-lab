# DEVLADLOG Copilot & AI

**Series slug:** `copilot-ai` · **Label:** COPILOT & AI · **Hashtags:** #Copilot #CopilotStudio #GitHubCopilot #GenerativeAI
**Audience:** Microsoft 365, Power Platform, Azure and developer teams who want to know what each Copilot really does
in their daily tools, what it costs, and how it compares with other AIs (Claude, OpenAI, Gemini, local models).
**Not from the blog:** this series has no devladlog.com Complete Guide; every fact comes from Microsoft Learn and the
official docs of each AI vendor, verified at build time.

## How it relates to the other series
Each category series already covers its product; this series is the cross-cutting "Copilot and AI in X" view, one
episode per area, built on the same fictional Contoso scenario and lab (series/LAB.md), and it links back to the
matching category episodes.

## Licensing reality in the lab (read before planning a demo)
- **Microsoft 365 Copilot (paid add-on): not licensed.** Copilot Chat (free with Entra accounts) is real; anything that
  needs the paid licence is clearly marked in demo.md with requirement and price, never faked. The owner decides
  whether to buy one seat for recording.
- **Copilot Studio:** viral trial licences on `labadmin` and `sam.demo`.
- **Power Platform Copilot features:** available in `DEV` / Sales trial where the region and settings allow; verify.
- **Copilot in Fabric/Power BI:** check on Learn whether the trial capacity supports it; if a paid F SKU is needed,
  say so with cost.
- **Dynamics 365 Copilot:** Sales trial environment (ends ~21 Dec 2026).
- **GitHub Copilot:** the owner's GitHub account (same as the mg-lab repo); confirm which plan at recording.
- **Security Copilot:** verify current licensing (SCU billing / E5 inclusion) on Learn and state cost; never enable
  paid capacity without the owner.
- **Other AIs:** Claude, OpenAI and Gemini APIs need the owner's own API keys (typed off camera, never committed);
  local models run on the recording laptop (RTX 5090, 192 GB RAM; Ollama / LM Studio already installed).
