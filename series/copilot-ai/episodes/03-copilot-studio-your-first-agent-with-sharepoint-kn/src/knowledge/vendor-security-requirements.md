# Contoso Vendor Security Requirements

The security team reviews vendors before onboarding is completed.

## Who must complete the security questionnaire

Every vendor that stores or processes Contoso personal data, or connects to the Contoso network, must complete the
security questionnaire. Vendors that only deliver goods, such as paper or furniture, do not.

## Accepted evidence

Contoso accepts a current ISO 27001 certificate or a SOC 2 Type II report that is not older than 12 months. Without
one of them the security team asks for the full questionnaire and may run its own assessment.

## Data processing agreement

A vendor that processes personal data signs the Contoso data processing agreement before it receives any data.
